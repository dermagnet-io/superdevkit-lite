# 根目录入口模板

用于 README、AGENTS 及实际使用的 harness 入口。共享规则有一个维护源；子目录入口只补局部差异。以下是文档骨架，不是要求每个项目新增所有入口。

## README.md

```markdown
# <项目名>

<产品解决什么问题、面向谁；说明当前可用范围。>

## 快速开始
<最短可用路径、必要前提与预期结果；复杂环境准备链接开发文档。>

## 使用与限制
<核心使用入口、已知限制；规划能力链接路线图并明确状态。>

## 文档导航
<产品、开发、架构等文档的用途与实际链接。>

## 贡献与许可
<按项目实际情况填写贡献入口、支持方式与许可。>
```

完成标准：使用者能理解产品并找到可用入口，不把未来能力当作现状。不足时优先补使用路径和限制，把工程治理正文移到其维护位置。

## AGENTS.md

```markdown
# <项目名> · 开发约定

<一句话项目定位；本文件的适用范围。>

## 任务分流
按当前请求、上下文和已有授权判断意图，不因出现技术名词就启动开发流程。
- 解释、比较方案、评估可行性，或明确要求“先讨论、不要修改”时，按讨论处理；可查代码和资料，默认不调用 Lite 开发流程。
- 明确要求实现、修复、重构或修改文件时，调用 SuperDevKit Lite 的 use，从适用阶段推进；沿用已确认需求和已有授权。
- 开发中途的提问或进度查询不自动取消任务，简要回答后继续；用户明确暂停或转为讨论时停止后续实施。
- 用户明确点名技能时按要求使用；仅评审、仅拆票或治理体检保持该范围，不自动扩展为实现。意图确有歧义时只澄清是否要执行修改。

## 项目边界
<影响开发决策的硬约束、数据保护与禁止修改区域及依据；详规放对应文档。>

## 文档位置与维护
系统级文档保存在 docs/ 根目录，01–07 按下表编号；编号表示人类阅读顺序，agent 按任务读取。单项需求文档保存在 docs/specs/。独立的部署、安全等文档从 08 起编号，并在下表追加阅读路由。
文档维护优先整理格式与补充内容，保留项目事实和当前开发信息。迁移列出原位置、目标位置与内容去向，经批准后同步引用；不得用模板覆盖或以精简为由删除当前开发内容。

## 按任务读取
| 当前问题 | 文档入口及用途 |
|---|---|
| 产品目标、范围或用户行为 | docs/01-product-requirement.md |
| 模块职责、接口或数据流 | docs/02-architecture.md |
| 重要取舍的依据 | docs/03-decision-log.md |
| 当前能力、下一步或阶段状态 | docs/04-roadmap.md |
| 交互、视觉或使用体验 | docs/05-ux-ux.md |
| 环境、实施或交付 | docs/06-developing.md |
| 验证选择与通过条件 | docs/07-testing.md |
| 单项需求、规则与验收细节 | docs/specs/ 下的相应需求文档 |
<部署、安全、数据等扩展主题按适用任务追加路由。>

## 技能路由
<仅引用项目实际可用的技能，并说明触发条件；不复制技能正文。>

## 完成与同步
<指向开发约定中的完成条件及文档维护规则；必要的局部例外在此说明。>
开发任务的最终回报遵循 Lite finalize 的固定项目、顺序与分项写法，按需提供“如何验收”。讨论会话正常回答，不套用开发回报格式。
```

生成入口时将表内路径写为实际可达的相对链接；迁移未获批准前保留原路由并说明目标位置。Lite 可用时，按需路由：治理整理用 setup；实现前用 start；需求歧义用 grill-to-spec；确认后拆票用 to-tickets；实现验证用 verify，前端体验变化用 frontend-check；完成约定交付用 finalize。use 提供统一选择入口。未安装的技能记录为接入建议，不声明已可用。

完成标准：能区分讨论与执行，典型任务能找到必要规则，开发回报有统一格式，不需每次读取全部文档。修改路由时核对目标存在、适用范围及子目录覆盖关系；已有有效规则不因不在模板中而删除。

## 其他 harness 入口

按实际宿主识别入口文件和加载规则。例如已有 CLAUDE.md 时，先核实其支持的导入方式，再拟定薄入口：

```markdown
# <harness> 项目入口

<使用该宿主已核实的机制加载共享 AGENTS.md；将此说明替换为实际加载语法。>

## 宿主差异
<仅记录该宿主必要的能力或操作差异，共享产品与质量约束仍由 AGENTS.md 路由。>
```

核对直接读取、显式导入、路径作用域与加载顺序；普通 Markdown 链接不等于自动加载。优先使用已支持的共享机制；确需保留镜像正文时，明确维护源和同步检查。不要默认建立符号链接，或在没有验证的情况下改写现有加载方式。尚无新会话证据时报告“入口已配置，加载未实测”。
